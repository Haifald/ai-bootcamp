# Deep Learning

Hands-on work covering neural network fundamentals, architecture design, optimization, and image classification.

## Contents

### Fundamentals
- **[neural-network-from-scratch.ipynb](fundamentals/neural-network-from-scratch.ipynb)** — builds neural-network concepts progressively from a single neuron through forward propagation, loss, gradient descent, backpropagation, and a multi-layer perceptron, then connects the implementation to Keras.
- **[keras-architecture-optimization.ipynb](fundamentals/keras-architecture-optimization.ipynb)** — compares Dense architectures on the digits dataset and explores learning rate, batch size, Early Stopping, Dropout, L2 regularization, and Batch Normalization.

### CIFAR-10 Dense Network
- **[cifar10-dense-network/](cifar10-dense-network/)** — an experiment-focused capstone investigating how far a fully connected network can go on flattened image data, including controlled tuning, error analysis, and pixel-shift sensitivity.
