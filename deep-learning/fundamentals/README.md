# Deep Learning Fundamentals

Hands-on notebooks covering neural network fundamentals, training behavior, architecture design, and optimization.

## Contents

### Neural Networks from Scratch
- **[neural-network-from-scratch.ipynb](neural-network-from-scratch.ipynb)** — builds neural-network concepts progressively from a single neuron through weighted sums, activation, forward propagation, loss, gradient descent, backpropagation, and a multi-layer perceptron, then connects the implementation to Keras.

### Architecture & Optimization
- **[keras-architecture-optimization.ipynb](keras-architecture-optimization.ipynb)** — compares shallow, medium, and deep Keras models on the digits dataset, then studies learning rate, batch size, Early Stopping, Dropout, L2 regularization, and Batch Normalization before final evaluation.
