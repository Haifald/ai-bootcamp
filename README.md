# Building and Developing AI Models Bootcamp

This repository documents the practical learning journey completed during the **Building and Developing AI Models Bootcamp** at Tuwaiq Academy. The work progresses from Python and exploratory data analysis through machine learning, deep learning, computer vision, large language models, and retrieval-augmented generation, culminating in a final applied AI project.

## Projects

### Python & Object-Oriented Programming

- **[Smart Training Center Management System](python/oop-training-center/)** — Builds a console application for managing trainees, course enrollment, attendance, results, certificate eligibility, and reports.

### Exploratory Data Analysis

- **[Airbnb Listings Exploratory Data Analysis](eda/airbnb-analysis/)** — Examines how listing, host, review, and location characteristics relate to city-relative Airbnb prices.

### Machine Learning

- **[Machine Learning Fundamentals](machine-learning/fundamentals/)** — Develops linear and logistic regression skills through from-scratch implementations and practice workflows.
- **[Diabetes Model Evaluation](machine-learning/diabetes-model-evaluation/)** — Compares binary classifiers using complementary evaluation metrics beyond accuracy alone.
- **[Airbnb Listing Segmentation](machine-learning/airbnb-clustering/)** — Groups Airbnb listings with similar characteristics into interpretable segments using clustering.
- **[Diabetes Diagnosis Prediction](machine-learning/diabetes-diagnosis-prediction/)** — Builds an end-to-end diabetes pre-screening classifier from demographic, lifestyle, risk-history, and clinical data.

### Deep Learning

- **[Deep Learning Fundamentals](deep-learning/fundamentals/)** — Develops neural networks from scratch and investigates architecture design, training behavior, and optimization with Keras.
- **[CIFAR-10 Dense Network](deep-learning/cifar10-dense-network/)** — Investigates what a fully connected neural network can learn from flattened image data and where the loss of spatial structure becomes limiting.

### Computer Vision

- **[EuroSAT Land Cover Classification: ResNet50 vs ViT](computer-vision/cnn-vs-vit-eurosat/cnn-vs-vit-eurosat/)** — Fine-tunes and compares a convolutional neural network and a Vision Transformer for satellite land-cover classification.

### Large Language Models & RAG

- **[Prompt Chaining for Iterative Story Generation](llms/prompt-chaining/)** — Connects multiple LLM calls into a controlled workflow that develops a story from premise to final output in successive stages.
- **[RAG from Scratch: PDF Question Answering](llms/rag/)** — Builds a retrieval-augmented generation pipeline that retrieves relevant PDF passages and uses them to produce grounded answers.

Each full project folder contains its own README with implementation details, methodology, results, and instructions, the LLM and RAG exercises are documented directly in their notebooks.

## Final Project

### Qaddir — AI-Powered Preliminary Vehicle Damage Assessment

Qaddir combines computer vision and generative AI to support preliminary vehicle damage assessment while keeping the human assessor in the decision loop.
