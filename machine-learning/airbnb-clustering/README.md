# Airbnb Listing Segmentation with Clustering

An unsupervised machine-learning analysis that segments Airbnb listings with similar characteristics and interprets the resulting groups.

## Workflow
- Prepare and scale clustering features
- Select and evaluate cluster configurations
- Apply clustering
- Profile and interpret the discovered segments
- Use dimensionality reduction for visualization where included in the notebook

## Notebook
`notebooks/airbnb-clustering.ipynb`

This project builds on cleaned Airbnb data from an earlier EDA workflow, but focuses specifically on unsupervised learning and listing segmentation.
