# Machine Learning Fundamentals

Hands-on notebooks covering core regression and classification concepts.

## Contents

### Linear Regression
- **linear-regression-from-scratch.ipynb** — builds simple linear regression manually using prediction, cost, gradients, and gradient descent, then compares it with scikit-learn.
- **regression-practice.ipynb** — additional simple and multiple regression practice, learning-rate experiments, vectorized regression, evaluation, and debugging.

### Logistic Regression
- **logistic-regression.ipynb** — binary classification workflow with probabilities, thresholds, confusion matrix, classification metrics, ROC-AUC, coefficient interpretation, and practice exercises.
